    지도 설정

    주드성경 지명 표시

    성경 지명·고대 참고 지명·현대 참고 지명은 주드성경 참고 자료를 지도 위에 얹어 보여 줍니다. 시대 개략도(색면) 장면에서는 이 표시가 나타나지 않습니다. 배경지도 자체의 글자는 아래 ‘배경지도’에서 켜고 끕니다.

    배경지도

    OpenFreeMap 배경지도 · 선택 불가(하나만 제공)

    배경지도는 OpenFreeMap(OpenMapTiles 스타일, OpenStreetMap 데이터)이며 표시하려면 인터넷 연결이 필요합니다. 해안선·수역·도로는 배경지도가 그리며 따로 켜고 끌 수 없습니다. 지형 음영은 제공하지 않습니다.

    지도 설정은 이 기기에 저장되며, 장면·시대·장소를 바꿔도 유지됩니다.

    주제·장면 표시

    • ●갈색 점 — 주제·여정 장면에 연결된 참고 지점 (위치를 확정하지 않습니다)
    • 시대 개략도 — 색면과 점선은 개략 범위·이동 방향이며 역사적 확정 경계가 아닙니다

    참고 표시

    • 현대 참고 (현대 도시)
    • 가참고 지명 (수역·지역·현대 지명)
    • 참고 배경 (OpenFreeMap 배경지도: 해안선·수역·도로·지명)

    표시는 참고 자료를 바탕으로 한 정보이며 성경 장소의 위치를 확정하지 않습니다. 이 지도는 교육용 참고 자료입니다.

    자료 출처

    • 배경지도OpenFreeMap © OpenMapTiles · Data from OpenStreetMap
    • 지도 엔진MapLibre
    • 현대 참고 지명Natural Earth 현대 지명 (Public Domain)
    • 참고 위치

    참고 위치는 기존 주제·여정 지도 자료를 바탕으로 한 참고 지점입니다. 시대 개략도의 색면과 점선은 화면 설명용 개략 표시이며 연구 데이터의 경계나 경로로 저장되지 않습니다.

    자세히 보기

    배경지도(해안선·수역·도로·지명)와 현대 참고 지명은 참고 배경이며 어떤 성경 장소의 위치도 확정하지 않습니다.

    참고 자료는 사람이 근거와 출처, 사용 조건을 검토한 뒤에만 연구 근거로 채택될 수 있으며, 자동으로 바뀌지 않습니다. 채택되어도 원래 출처와 다른 견해는 함께 남습니다.

    시대 개략도의 색면과 점선은 확정된 길이나 경계가 아니라 대략적인 범위와 이동 방향을 보여 주는 표시입니다.

    표시된 점은 주제·여정 장면의 참고 지점과 현대 도시이며, 성경의 장소가 정확히 그곳이라는 뜻은 아닙니다.

    배경지도·현대 지도: MapLibre | OpenFreeMap © OpenMapTiles Data from OpenStreetMap · 현대 참고 지명: Natural Earth(퍼블릭 도메인) · 지명 좌표 대조: OpenBible.info(CC BY 4.0). 경로와 범위는 강의용 개략선이며, 위치가 불확실한 곳은 ‘추정’(?)으로 표시했습니다.

    원어 데이터 출처·라이선스 (6종)

    원어 본문·형태 분석·사전 데이터는 출처와 이용 조건이 각각 다릅니다. 다음 안내는 원천 자료의 이용 조건 설명이며 JudeBible 연구 원고의 별도 공개 승인을 뜻하지 않습니다.

    1. Open Scriptures Hebrew Bible (OSHB) (v.2.2)

      Original work of the Open Scriptures Hebrew Bible available at https://github.com/openscriptures/morphhb

      라이선스: CC BY 4.0 (OSHB work); WLC text is in the Public Domain · 이용 조건 · 원출처

      JudeBible에서의 가공: Token re-keying, per-book packaging, dictionary-encoded lemma/morph; raw token text preserved.

    2. SBL Greek New Testament (SBLGNT) (v1.2)

      SBL Greek New Testament, https://github.com/Faithlife/SBLGNT, licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

      라이선스: CC BY 4.0 · 이용 조건 · 원출처

      JudeBible에서의 가공: Split into pre/word/post parts (lossless), per-book packaging; text bytes preserved.

    3. MACULA Greek Linguistic Datasets (SBLGNT edition) (24.06.17)

      MACULA Greek Linguistic Datasets, available at https://github.com/Clear-Bible/macula-greek/

      라이선스: CC BY 4.0 · 이용 조건 · 원출처

      JudeBible에서의 가공: Column subset, re-keyed by (book, chapter, verse, token_index) onto SBLGNT tokens, dictionary-encoded; 677 tokens excluded (EXCLUDED_PROVENANCE_HOLD). The MACULA text column is not used.

    4. Open Scriptures Hebrew Lexicon (2019-09-02)

      Open Scriptures Hebrew Lexicon, https://github.com/openscriptures/HebrewLexicon, licensed CC BY 4.0 (credit: Open Scriptures Hebrew Bible Project)

      라이선스: CC BY 4.0 (stated in readme.md; GitHub shows no LICENSE file). Strong's Hebrew Dictionary and BDB text themselves remain public domain. · 이용 조건 · 원출처

      JudeBible에서의 가공: Only AugIndex.xml + LexicalIndex.xml are used for OSHB augmented-lemma to lexical-id binding; only Korean glosses marked VERIFIED in the local review gate are emitted. BDB/TWOT/Strong definitions are not shipped.

    5. Dodson Greek-English Lexicon (2018-01-11)

      Dodson Greek-English Lexicon (public domain / CC0), https://github.com/biblicalhumanities/Dodson-Greek-Lexicon

      라이선스: CC0 1.0 Universal (repository LICENSE); README states the lexicon is in the public domain in all its forms. Derived from Jeffrey Dodson's public-domain Greek NT lexicon; XML conversion by Ulrik Sandborg-Petersen / Jonathan Robie. · 이용 조건 · 원출처

      JudeBible에서의 가공: Only dodson.xml headword + brief gloss are used for lemma binding; only Korean glosses marked VERIFIED in the local review gate are emitted.

    6. STEPBible Data — Tyndale Brief Lexicon of Extended Strongs (TBESH / TBESG) (commit 1f3423d4)

      Data created by www.STEPBible.org based on work at Tyndale House Cambridge, licensed under CC BY 4.0 (https://github.com/STEPBible/STEPBible-Data).

      라이선스: CC BY 4.0 — data created by www.STEPBible.org based on work at Tyndale House Cambridge · 이용 조건 · 원출처

      JudeBible에서의 가공: Only the Gloss column is used; the Meaning column (TBESH: Online Bible abridged BDB, permission required; TBESG: Abbott-Smith) is not read or shipped. Entries are keyed by dStrong, bound to OSHB/MACULA lemmas, and re-encoded as [dStrong, gloss, reviewCodes]; gloss text is unchanged.
